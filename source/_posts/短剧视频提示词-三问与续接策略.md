分镜写完了，冻结关键帧也写完了，接下来是把它变成视频提示词。

这一步最容易出的错是**没搞清这镜到底是文生还是图生**就动笔。写错了基础假设，
后面整段正文的写法都是反的——文生视频却只写"保持已有外观"，等于什么都没说，
因为执行端根本没收到可供保持的图片。

## 一、先答三个问题

拿到分镜的"输入参考图"字段，逐槽位回答：

1. **路径**回答"送哪一张图"
2. **用途**回答"它在本镜负责什么"
3. **顺序**回答"在可复制正文里叫哪个标签"

> **答不了这三问的槽位，不算准备好。**

这三问同时也是自查表。很多"绑了图但提示词说不清画面里有谁"的文档，
根子就在槽位里没写用途。

## 二、四种状态，只有一种能投产

| 分镜里的写法 | 实际含义 | 走哪条路 |
| --- | --- | --- |
| 有可读的真实 `REF-...` | 图在项目里 | 图生视频，可投产 |
| `PLAN-...` 槽位 | 图在创作者自己的工具里 | 图生视频，**项目内无文件，不能投产** |
| `无（创作者已明确选择文生视频）` | 明确不用图 | 文生视频 |
| `无（待补参考图：……）` / 普通的"无" | **未准备好** | 先补图，不是文生授权 |

第三行和第四行只差几个字，含义完全相反。**"没有图"不等于"不用图"**：
前者是缺口，后者是选择。把缺口当选择处理，就是静默降级——生成出来的东西没人对得上。

`PLAN-...` 那一行也值得单独说。它语法上和 `REF-...` 完全一样，
只是把项目相对路径换成了条目 ID。它声明的是"这张图由创作者在生成时按这个顺序挂载"，
**不声称项目里有文件**，所以不能拿来投产。真实文件进了项目，才改写成 `REF-...`。

## 三、文生视频必须自己交代静态事实

图生视频有参考帧兜底，文生视频没有。所以文生视频**必须写非空的"静态视觉锚点"**，
并且把它原样纳入可复制正文。

要交代的是：人物、造型、地点、构图、光线中，**本镜必要的事实**。

最典型的错误写法是：

```
preserve the character's appearance
保持已有外观
```

这句话对文生视频毫无意义——**执行端没有收到可供保持的图片**。
要么把外观写出来，要么承认这镜需要参考图。

## 四、"生成方式"只有两个值

这个字段只写两个精确值：

```
生成方式：图生视频
生成方式：文生视频
```

**不追加模型名、方言或 full-reference 之类的说明。** 模型说明放在正文结构里。

那么具体走首帧、首尾帧还是多槽参考？**由各槽位的"用途"组合读出来**：

| 用途组合 | 走什么 |
| --- | --- |
| 只有一张 `起始帧` | 首帧 |
| `起始帧` + `结束帧` | 首尾帧 |
| `起始帧` 与人物/地点/道具图同时存在，或只有这些图 | 多槽参考 |

具体怎么翻译成供应商的字段，由对应模型的方言负责。

## 五、时长和台词：两个数字陷阱

### 时长必须落在模型原生区间

每镜时长要落在目标模型档案的原生区间内。不在区间内就**回到分镜修订**。

两条禁令：

- **不能写完提示词后留给执行端报错**
- **不能在正文里暗自改变时长**（写了 5 秒就是 5 秒，不能正文里偷偷按 8 秒描述）

### 秒段加总正确，不代表台词说得完

有对白、旁白或画外音时，要同时核对分镜"声音"里的估时依据和实际可用发声窗口。

> **秒段加起来等于总时长，不等于这几句话说得完。**

一句 4 秒的台词 + 2 秒的起身动作 + 1 秒的反应，塞进 5 秒的镜头里，
数学上能凑，物理上不行。缺少估时依据就补做判断，别猜。

## 六、动作链：把"起点 → 唯一动作 → 终点"完整实现

可复制正文要**完整实现**分镜定下的那条状态链。

硬要求：**交接、换手和道具落位不跨镜省略。**

道具从 A 手里到 B 手里，这个过程必须发生在某一镜内。
如果分镜的终点写着"杯子在桌上"，而上一镜的终点是"杯子在 A 手里"，
中间没有镜头交代——那这个杯子就是靠镜外瞬移过去的。

正文的结构大致是：

```
静态锚点 → 起点 → 唯一动作（触发、接触、落点）→ 次级反应 → 运镜 → 声音 → 终点
```

必要时用秒数分段。**下一镜从上一镜的终点继续，不另造镜外转换。**

另外两条具体要求：

- **表演写动作与反应**，不写无法执行的抽象结果（"她感到绝望"没法执行，"她把手里的信捏成一团"可以）
- **运镜与人物动作不争夺注意力**，复杂运镜必须有叙事理由

## 七、文字政策：默认关，但不是一刀切

默认规则：**正文直接写明全镜任何时刻都不生成非画内字幕、caption 和对白文字叠加。**

注意这里的措辞——不是写抽象的"文字层为空"，而是直接声明不生成。
而且这条**与旗帜、标牌、屏幕等画内文字是独立的**。

也就是说：

- 非画内字幕 → 默认不生成
- 画内精确文字（门牌、手机屏幕、信件）→ **独立的允许集合**，逐字写明字符、语言、承载面和位置

两个方向都不能搞错：不能因为关了字幕就把画内文字也关掉，
也不能让未批准的文字混进来。画内精确文字要用 `exact_readable` 逐字写，
**不能用全局的 no-text 覆盖**。

还有一条容易被忽略的：**正文里被引号或 `<d>` 包起来的中文必须逐字来自剧本**。
台词不在剧本里，就回到写作阶段改剧本，**不要在提示词里改台词**。

## 八、声音同轨：逐字台词只出现一次

目标模型如果画面和声音一次生成，声音写法要特别注意：

- 把允许的发声按**来源、说话人、口语语言和顺序**写成完整时间线
- 每句从原文**首字到末字**
- 逐字对白在单镜可复制正文里**只出现一次**

第三条的意思是：视觉动作段如果也提了这句话，就只按时间和说话人**引用**这个声音事件，
**不再抄一遍台词**。抄两遍的后果是模型可能把同一句话生成两次。

无对白镜要写清**底声或静默及其覆盖区间**。嘴部动作按剧本表演，
不默认强制闭嘴——除非剧本要求。

已确认的发声边界（禁止外语前导、禁止语气词、禁止额外人声）在完整时间线末尾**合并写一次**，
不要靠"只包含……"让执行端猜。

## 九、续接：默认从上一段的结果往下接

这是整套流程里最反直觉、也最省钱的一条：

> 同一连续时空中相邻的正式生成段，**默认选择"从上一段生成结果续接"**。
> "一镜一生成"只决定每次装一个镜头，**不等于各镜独立文生**。

续接时第二段要同时绑定两样东西：

- **上一段的实际视频** → 负责动作、节奏、声音连续
- **从该视频取得的实际尾帧** → 负责下一段的可见起点

这两个职责不能混。素材 role 怎么翻译由模型方言决定。

关键限制：**未取得真实产物时，后续段标为"待续接、不可提交"**，
写明缺少这两项真实输入，保留内容草案。

**不得把它降级成独立文生视频，也不用计划尾帧、关键帧提示词或文字描述冒充接力输入。**
文字描述不是尾帧。

## 十、几条贯穿的要求

- 从**可见起点**开始，以**可验证终点**结束
- 主体、动作对象、方向、幅度、速度和先后关系明确
- 本镜命中的**连续性锁，锁面原样出现在可复制正文里**——颜色、材质、形制这类跨镜不变事实不靠模型记忆
- 上游持续关系用**贯穿状态和允许动作通道**表达，避免重复限制或冲突动作
- 正文**可直接复制**，不含占位符、流程说明、文件路径或 QA 结论
- 不跨下一镜、不要求互斥动作、不让人物或道具瞬移变形

## 十一、小结

这一阶段的全部工作可以概括成一句话：

> **把分镜里已经定好的东西，翻译成执行端能精确执行的形式。**

它不新增创作——不改分镜边界、不写新台词、不补新动作。
它只做翻译，而且翻译要精确到"哪一张图、负责什么、按什么顺序"。
